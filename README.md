# Kek950 Tap

## How do I install these formulae?

`brew install kek950/tap/<formula>`

Or `brew tap kek950/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "kek950/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
